# Receipts Live In One Folder

Every receipt, slip and form goes into one scanned folder the day it arrives, named `YYYY-MM-DD what.pdf`. Filing the [[Tax Return 2026]] then means opening one folder instead of searching three inboxes. The same folder holds the [[Passport Renewal]] form.
