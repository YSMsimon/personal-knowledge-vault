# Lease Renewal Needs Sixty Days Notice

The lease requires sixty days' written notice before leaving. Missing it would have meant paying an extra month, which is why the [[Apartment Move]] started in September. Dates like this belong in `due:`, not only in a sentence; see [[How This Vault Works]].
